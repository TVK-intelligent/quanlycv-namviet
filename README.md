Công nghệ: HTML5 + CSS3 + JavaScript (ES6) (Frontend Single Page Application / Static HTML). Không Backend, Không API, Không Database.Lưu trữ dữ liệu: Mô phỏng hoàn toàn bằng LocalStorage (Mock Data & Client-side State Management).Phong cách thiết kế: Enterprise, hiện đại, tối giản, chuyên nghiệp, lấy cảm hứng từ Jira, Redmine và ClickUp.  2. LUỒNG TRẠNG THÁI & WORKFLOWS (BUSINESS LOGIC)7.1 Luồng Vòng đời Công việc (Task Lifecycle Gateway Workflow)Plaintext       [  TO_DO  ]  <---- (Initial State)
            |
            |--- [Check Gate 1: DoR Checklist == 100%] 
            |    (Nút "Start Working" được mở khóa)
            v
     [ IN_PROGRESS ] <---> [ BLOCKED ] (Nghẽn - Bắt buộc nhập lý do)
            |
            |--- [Check Gate 2: DoD Checklist == 100% AND Proof URL valid]
            |    (Nút "Submit Task" được mở khóa)
            v
      [ IN_REVIEW ] 
            |
            +---> [ QA Tester Reject ] -------> (Trở lại IN_PROGRESS + Bắt buộc nhập lỗi + Trừ điểm FTPR)
            |
            +---> [ QA Tester Pass ] ---------> (Chờ PM Approve)
                                                    |
                                                    v
                                                [  DONE  ] (Khóa dữ liệu Log-time & Chốt điểm KPI On-time)
7.2 Luồng Duyệt Cấp Nhân sự (Resource Request Workflow)PM tạo ResourceRequest (% Capacity, Target Dept) → Status = PENDING.Trưởng phòng (Head) mở Dashboard Sức tải → Xem chỉ số WSI dự kiến của nhân viên.Head chọn Approve (Chỉ định nhân sự) → Status = APPROVED, tạo ProjectMember | Hoặc chọn Reject → Kích hoạt Modal nhập lý do từ chối → Status = REJECTED.7.3 Luồng Lùi Deadline & Overdue FlagCron job quét thời gian thực: Nếu Current_Date > DueDate AND Status != DONE → IsOverdue = true (Badge đỏ).Nhân viên tạo TaskExtensionRequest → PM/Head Approve → DueDate cập nhật ngày mới & IsOverdue tự động reset về false
